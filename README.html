sync-profile

把你的开发经验装进口袋，带到任意项目
这是做什么的？
一个 Skill，把你的编码习惯、AI 协作规则、踩坑记录打包成可跨环境复制的种子包。
初始化新项目时，AI 自动认识你。

四个操作

/sync-profile init
新项目初始化。
问语言和版本 → 生成项目 CLAUDE.md + LESSONS.md + 权限配置。
只复制匹配语言和版本的踩坑记录，不相关的跳过。
/sync-profile pull
回收项目里新踩的坑回种子包。
AI 逐条判断归类，确认的自动整理、不确定的问你。
这样下次 init 其他项目时也有这些教训。
/sync-profile refresh
种子包更新了，同步到已有项目。
保留你项目里手写的内容，只覆盖模板部分。
/sync-profile merge
家里和公司的种子包各自改了，合并。
比对两边文件的 MD5 → 找出差异 → 逐文件展示让你选保留哪边。

目录结构

sync-profile/
├── README.html ← 本文件
├── SKILL.md ← AI 读的指令
├── seed.yaml ← 版本号 + changelog
├── profile/ ← 你的个人侧写
├── config/ ← 全局配置模板
├── knowledge/ ← 踩坑记录（按语言版本分层）
├── scaffolds/ ← 项目骨架模板
└── scripts/ ← PowerShell 辅助脚本

怎么用

家里维护种子包
直接编辑 profile/、knowledge/ 里的文件。
改完跑 /sync-profile refresh 同步到已有项目。
复制到公司
把整个 sync-profile/ 目录丢进 U 盘。
到公司复制到 ~/.claude/skills/ 即可使用。
无需 git，无需联网，纯文件。
经验带回家
公司项目跑 /sync-profile pull → 新教训写入公司种子包。
U 盘带回家 → 跑 /sync-profile merge 合并到家里种子包。

内网可用 · 纯文件 · 工具无关 · 零依赖
